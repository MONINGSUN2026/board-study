# Node.js 학습

> `frame/nodejs` 브랜치에서 Node.js 기반 게시판 백엔드를 단계적으로 학습한다.

## 목적

Node.js의 실행 구조와 비동기 처리 방식을 이해하고, 게시판 도메인을 단계적으로 구현한다.
공통 UI와 요구사항은 `main` 브랜치의 자료를 참조하며, Node.js 구현과 학습 기록은 이 브랜치에서 관리한다.

## 학습 범위

- 요구사항 분석부터 배포까지의 개발 흐름
- Node.js 실행 환경과 npm
- 게시판 요구사항의 단계별 구현
- API·데이터베이스·인증·파일 처리
- 테스트·보안·운영·배포

## 시작 전 준비

- Node.js LTS와 npm 설치 확인
- `node --version`, `npm --version`으로 버전 기록
- 프로젝트 초기화 및 의존성 선택
- 공통 요구사항과 데이터베이스 문서 확인
