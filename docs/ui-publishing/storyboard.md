# UI 스토리보드 (Storyboard)

화면 간 흐름과 와이어프레임, 주요 인터랙션을 정의한다.
개별 화면의 구성 요소 목록은 `screen-specification.md`를 참조한다.

## 1. 화면 흐름 (User Flow)

```text
[진입] ──▶ 게시글 목록 (/posts)
                │
                ├─ 게시글 클릭 ─▶ 게시글 상세 (/posts/{id})
                │                      │
                │                      ├─ 이전/다음 글
                │                      ├─ 댓글/대댓글 작성
                │                      ├─ 수정 (작성자) ─▶ 게시글 수정
                │                      └─ 삭제 (작성자)
                │
                └─ 글쓰기 (회원) ─▶ 게시글 작성 (/posts/new)
                                        └─ 등록 후 ─▶ 상세로 이동

[비회원]
   └─ 로그인 (/login)
        ├─ 성공 ─▶ 이전 화면 복귀
        └─ 회원가입 (/signup) ─▶ 로그인

[회원]     ─▶ 내 정보 (/me)
[관리자]   ─▶ 관리자 (/admin)
```

## 3. 주요 인터랙션

| 화면 | 요소 | 동작 | 결과 |
| --- | --- | --- | --- |
| 목록 | 행 클릭 | 상세로 이동 | `/posts/{id}` |
| 목록 | 검색/필터/정렬 | 쿼리 반영 재조회 | 목록 갱신 |
| 목록 | 글쓰기 | 작성 화면 이동 | `/posts/new` (회원) |
| 상세 | 이전/다음 | 해당 글 상세 이동 | `/posts/{id}` |
| 상세 | 댓글 등록 | 댓글 추가 | 댓글 목록 갱신 |
| 상세 | 수정/삭제 | 작성자 검증 후 동작 | 수정 폼/삭제 |
| 작성 | 등록 | 유효성 검증 후 저장 | 상세로 이동 |
| 작성 | 임시저장 | 임시 상태 저장 | 작성 화면 유지 |
| 로그인 | 로그인 | 인증 성공 시 복귀 | 이전 화면 |
| 공통 | 모바일 메뉴 | nav 토글 | 메뉴 열림/닫힘 |
