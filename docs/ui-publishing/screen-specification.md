# 화면 정의 (Screen Specification)

퍼블리싱할 화면을 정의한다. 기준은 `../common/requirements.md`의 기능적 요구사항이다.
현재 단계는 **백엔드·프레임워크 없이 UI 마크업만** 작성하는 퍼블리싱 시도에 해당한다.

## 화면 목록

| ID | 화면 | 경로 | 권한 |
| --- | --- | --- | --- |
| LAYOUT | 공통 레이아웃 | (전 화면) | 공통 |
| POST-LIST | 게시글 목록 | `/posts` | 비회원 이상 |
| POST-DETAIL | 게시글 상세 | `/posts/{id}` | 비회원 이상 |
| POST-WRITE | 게시글 작성 | `/posts/new` | 회원 |
| POST-EDIT | 게시글 수정 | `/posts/{id}/edit` | 작성자/관리자 |
| AUTH-LOGIN | 로그인 | `/login` | 비회원 |
| AUTH-SIGNUP | 회원가입 | `/signup` | 비회원 |
| MY-PAGE | 내 정보 | `/me` | 회원 |
| ADMIN | 관리자 | `/admin` | 관리자 |

> 권한은 `requirements.md` 2장 페르소나(비회원/회원/관리자) 기준.

## 공통 레이아웃 (LAYOUT)

모든 화면에 공통으로 사용되는 구조다.

```
┌─────────────────────────────────┐
│ Header: 로고 | nav(목록/작성) | 로그인/프로필│
├─────────────────────────────────┤
│ (페이지별 콘텐츠)               │
│                                 │
├─────────────────────────────────┤
│ Footer: copyright, 링크         │
└─────────────────────────────────┘
```

| 영역 | 내용 | 비고 |
| --- | --- | --- |
| Header | 로고, 게시판 nav, 로그인 상태 표시 | 비회원: "로그인" 버튼 / 회원: 프로필·로그아웃 |
| Footer | 저작권 등 공통 정보 | 전 화면 동일 |

## 게시글 목록 (POST-LIST)

- **목적**: 게시글을 검색·필터·정렬·페이징하여 조회한다.
- **주요 UI**
  - 상단: 제목/본문/작성자 검색 입력, 검색 버튼
  - 필터: 카테고리, 태그
  - 정렬: 최신순 / 조회순 / 추천순
  - 목록: 번호, 제목, 작성자, 조회수, 작성일
  - 하단: 페이지네이션
  - 우측/상단: "글쓰기" 버튼 (회원)
- **데이터(목업 기준)**: 게시글 항목 10~20개 노출

## 게시글 상세 (POST-DETAIL)

- **목적**: 게시글 본문과 댓글을 조회하고, 이전/다음 글을 탐색한다.
- **주요 UI**
  - 제목, 작성자, 작성일, 조회수
  - 본문
  - 이전 글 / 다음 글 링크
  - 댓글 목록 + 대댓글 (depth 처리)
  - 댓글 작성 폼 (회원), 수정/삭제 버튼 (본인/관리자)
  - 하단: 목록으로, 수정, 삭제 버튼

## 게시글 작성 (POST-WRITE)

- **목적**: 새 게시글을 작성한다.
- **주요 UI**
  - 제목 입력
  - 카테고리 선택, 태그 입력
  - 본문 에디터 영역 (퍼블리싱 단계에서는 textarea 또는 기본 에디터 UI)
  - 이미지 업로드 버튼
  - 임시저장 / 등록 / 취소 버튼

## 게시글 수정 (POST-EDIT)

- POST-WRITE와 동일한 레이아웃.
- 기존 값이 pre-fill된 상태로 노출.

## 로그인 (AUTH-LOGIN)

- **목적**: 회원 인증 진입.
- **주요 UI**: 아이디, 비밀번호, 로그인 버튼, 회원가입 링크

## 회원가입 (AUTH-SIGNUP)

- **목적**: 회원 등록.
- **주요 UI**: 아이디(중복확인), 비밀번호, 비밀번호 확인, (이메일/닉네임 등), 가입 버튼

## 내 정보 (MY-PAGE)

- **목적**: 내 정보 조회/수정, 내가 쓴 글 목록 접근.
- **주요 UI**: 프로필 정보, 수정 폼, 내 글/내 댓글 목록

## 관리자 (ADMIN)

- **목적**: 공지 작성, 전체 글/댓글/회원 관리.
- **구조**: 탭(공지 / 게시글 관리 / 댓글 관리 / 회원 관리)으로 구분한다.

| 탭 | 기능 | 목록 컬럼 | 액션 |
| --- | --- | --- | --- |
| 공지 | 공지 작성·관리 | No, 제목, 작성자, 작성일 | 수정 / 삭제 |
| 게시글 관리 | 전체 게시글 조회·삭제 | No, 제목, 작성자, 조회, 작성일 | 삭제 |
| 댓글 관리 | 전체 댓글 조회·삭제 | No, 내용, 작성자, 대상 글, 작성일 | 삭제 |
| 회원 관리 | 회원 조회·차단·삭제 | No, 아이디(닉네임), 이메일, 가입일, 상태 | 차단 / 삭제 |

## 퍼블리싱 범위 (1차)

우선순위가 높은 화면부터 퍼블리싱한다.

1. [ ] LAYOUT — 공통 header/footer 템플릿
2. [ ] POST-LIST — 게시글 목록
3. [ ] POST-DETAIL — 게시글 상세(+댓글)
4. [ ] POST-WRITE/EDIT — 작성·수정
5. [ ] AUTH-LOGIN / AUTH-SIGNUP — 로그인/회원가입
6. [ ] MY-PAGE, ADMIN — 선택(시간될 때)
