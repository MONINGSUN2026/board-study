# Node.js 실습 중심 학습 계획

이 문서는 공통 게시판 요구사항을 Node.js로 단계적으로 구현하며, 설계부터 배포까지의 개발 흐름을 학습하기 위한 커리큘럼이다.
이론은 실제 구현에 필요한 범위에서 학습하고, 학습한 내용은 즉시 요구사항 구현과 검증에 적용한다.

## 학습 원칙

- `docs/common/requirements.md`와 `docs/common/features.md`를 구현 기준으로 사용한다.
- 각 단계는 `이론 학습 → 설계 판단 → 요구사항 구현 → 실행·테스트 확인` 순서로 진행한다.
- 이론만 별도로 진행하지 않고, 가능한 한 작은 기능을 끝까지 연결해 구현한다.
- 스택이나 도구의 선택이 필요한 시점에만 관련 이론을 학습한다.
- 각 단계가 끝나면 실제로 이해한 내용과 시행착오를 `docs/nodejs/learnings.md`에 기록한다.
- 이 문서는 학습용 커리큘럼이며, 실제 기능 목록이나 운영 문서를 대신하지 않는다.
- 이 프로젝트의 목적은 Node.js 게시판 완성 자체가 아니라, 동일한 요구사항을 여러 스택으로 구현하며 사용법·구조·흐름을 비교 학습하는 것이다.

## 구현 순서 개요

```text
환경 준비
  → 요구사항·도메인 설계
  → Node.js 애플리케이션 기반
  → 자유게시판 조회
  → 인증·인가
  → 자유게시판 작성·수정·삭제·댓글
  → 카드게시판·파일
  → 홈·검색·탐색
  → 테스트·보안·운영
  → 배포·회고
```

- 공통 Docker 데이터베이스와 Node.js 애플리케이션의 연결 흐름을 이해한다.

- `package.json`, lock 파일, 환경 변수

### 실습 범위

- Node.js와 npm 설치·버전 확인
- Node.js 프로젝트 초기화
- 최소 실행 명령과 기본 서버 확인
