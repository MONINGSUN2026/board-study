# AGENT.md

> AI 보조원(assistant) 전용 작업 지시 문서.
> 사람용 문서는 `README.md`를 참조한다.

## 역할

- 사용자의 학습/실습을 보조한다.
- 파일 생성·수정·읽기, Bash 명령 실행, 코드 작성·수정·리팩토링·테스트를 담당한다.
- 삭제 작업은 사용자 승인 필수.
- 모든 응답은 **한국어**로 한다.

## 권한 / 한계

- 워크스페이스 디렉토리 내에서만 작업한다.
- `node_modules/` 등 탐색 제외 대상은 검색에서 제외한다.
- `.private/` 디렉토리는 접근하지 않는다.

## 언어 규칙

- 응답 메시지: **한국어**
- 주석, 문서(README 등): **한국어**
- 커밋 메시지(subject, body): **영어**
- 식별자(변수/함수/클래스/파일명): **영어**

## 컨벤션 참조

- 코드/Git/브랜치 컨벤션과 공통 구조는 `README.md`의 "컨벤션" 섹션을 따른다.
- 스택/시도 단위는 **디렉토리가 아니라 branch**로 구분한다.
- 산출물 문서는 root의 `README_<stack-name>.md`와 `docs/<stack-name>/` 아래에 작성한다.

## 작업 절차

1. 변경 작업 전 변경 범위와 이유를 짧게 요약한다.
2. 코드 변경은 작은 단위로 커밋한다(Conventional Commits).
3. 작업 완료 후 커밋 해시와 변경 요약을 보고한다.

## 절대 하지 말 것

- 사용자 승인 없는 파일 삭제
- API 키·비밀번호 등 민감 정보 커밋
